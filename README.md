# kanishkmittal.dev

I'm Kanishk Mittal, a software engineer, and this is my personal site.

The page sits on top of a 3D knowledge graph of my work: where I've worked, what I've built, and the tools I use. It opens as a cloud of scattered points, resolves into the graph, and the camera flies from cluster to cluster as you scroll.
